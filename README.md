# numair.vercel.app

Personal landing page for Numair Shahzada, deployed on Vercel from `main`.

- `index.html`: the whole page (inline CSS, fonts and script)
- `public/Numair-Shahzada-Resume.pdf`: resume download linked from the footer

Do not edit these files here. They are copied from the `My Portfolio` folder
(`numair-shahzada.html` and `resume/`) by `scripts/sync-site.sh`, which commits
and pushes automatically.

Local preview: `npm install && npm run dev`
